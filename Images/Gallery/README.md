# ActiBoard billedgalleri

Galleriet bruges af aktivitets-, lokations-, medarbejder- og temaeditoren.
Tilføj billeder i Activities, Locations, Employees eller Themes.
Filnavnet uden endelse bliver navnet i galleriet.

Understøttede formater: PNG, JPG/JPEG, BMP, GIF og TIFF.
Billederne kontrolleres med WPF. Billeder, der ikke kan åbnes, springes over.
WebP og HEIC medtages ikke, da understøttelsen afhænger af installerede codecs.

Billederne kopieres automatisk til output og ved publicering.
Aktiviteter og lokationer får deres egen billedkopi ved gemning.
Medarbejdere og temaer får en kopi ved valg.
Sletning af en aktivitet, lokation eller medarbejder sletter derfor ikke galleriets billede.

Startindholdet er kopier af projektets eksisterende aktivitets- og lokationsbilleder.
Medarbejder- og temakategorierne er tomme, indtil der tilføjes billeder.
